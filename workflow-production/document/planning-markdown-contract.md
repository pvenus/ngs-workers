# NPC 종합 생성: 문서 워커 Markdown 계약

정식 요청 하나의 문서 단계입니다. 작성 순서는 **인물 개요 → 포트레이트용 아트 → 대표 포즈 기획 → 아이들 포즈 기획**입니다. 모든 문서는 한국어 Markdown을 하나의 `content` 문자열로 저장합니다. 각 문서에는 제목 하나(`#`)와 아래의 필수 목차(`##`)만 순서대로 넣고, 목차 사이에는 비어 있지 않은 본문을 씁니다.

## 1. 인물 개요 · `npc.plan-overview`

| 필수 목차 | 적을 내용 |
|---|---|
| 인물과 역할 | 같은 NPC의 정체성, 역할, 작품 속 위치 |
| 관계와 서사 | 근거에 있는 관계, 동기와 서사 기능. 관계가 없으면 미확인으로 표기 |
| 현재 상태 | 요청의 액트·챕터에서 적용되는 사회적 역할, 신체·복장·장비 상태 |
| 확정과 미정 | 확인한 사실, 미정 사항, 설정을 바꾸지 않는 제한된 제안의 구분 |

인물 개요에서 새 가족 관계, 과거 사건, 장비 등 영속 설정을 임의로 확정하지 않습니다.

## 2. 포트레이트용 아트 · `npc.plan-portrait-art`

| 필수 목차 | 적을 내용 |
|---|---|
| 이미지 제작 지시 | 첫 블록. 외형·복장·색·화풍을 독립적으로 읽을 수 있는 단일 인물 전신 지시문 |
| 인물 외형 | 나이대, 체형, 얼굴, 머리, 실루엣의 결정 또는 근거와 구분된 제안 |
| 복장과 색 | 상·하의와 신발, 소재, 주색·보조색, 유지할 노출·가림 조건 |
| 화풍과 표현 금지 | 포트레이트용 화풍, 배경·다른 피사체·임의 소품·잘림 금지 |
| 확정과 제안 | 기존 확정 외형과 새 시각 제안의 적용 경계 |

인물 개요에서 정체성과 상태를 이어받습니다. 미정 외형은 기존 설정인 것처럼 적지 않고 시각 제안 한 안으로 명확히 구분합니다. 첫 블록에는 장면이나 배경을 만들지 않는 인물 단독 전신, 투명 배경, 인물·복장 조건을 직접 쓰며 파일 경로·URL·해시는 넣지 않습니다.

## 3. 대표 포즈 기획 · `npc.plan-representative`

| 필수 목차 | 적을 내용 |
|---|---|
| 포즈 제작 지시 | 첫 블록. 공통 아트 위에 적용할 단일 대표 포즈의 짧은 지시문 |
| 대표 자세와 표정 | 무게중심, 몸·손·고개의 방향, 표현할 표정 |
| 카메라와 구도 | 각도와 프레임 범위, 축소 후 실루엣·밑단의 가독성 |
| 검수 기준 | 인물·복장 보존 및 다른 인물, 배경, 잘림, 중복 팔다리 등 확인 |

공통 외형을 다시 정하지 않습니다. 8방향 표나 걷기·뛰기 검수 기준을 대표 포즈 지시문에 넣지 않습니다.

## 4. 아이들 포즈 기획 · `npc.plan-idle`

| 필수 목차 | 적을 내용 |
|---|---|
| 포즈 제작 지시 | 첫 블록. 정지 상태의 자세만 달라지는 짧은 지시문 |
| 유지할 외형 | 공통 아트와 대표 기획에서 이어받는 얼굴, 옷, 색, 체형, 가림 조건 |
| 정지 자세 | 발 간격·무게중심·손·고개·시선·표정 |
| 방향별 가림 | 해당 각도에 적용되는 근거 있는 가림. 정지 측면 규칙을 이동으로 전파하지 않음 |
| 검수 기준 | 외형 불변, 본문과 포즈 일관성, 프레임·밑단·팔다리 확인 |

### 실행과 검증

- 앞 문서의 본문은 PDS의 정식 읽기 결과와 현재 Filex 다운로드 파일의 검증된 바이트에서 일치해야 합니다.
- 아트와 포즈의 첫 블록은 최대 1,000자이며 파일·경로·해시 대신 시각 요소를 직접 설명합니다.
- 허용된 Markdown 구조나 필수 목차를 위반하면 게시하지 않습니다. 각 워커는 자신이 승인받은 작업 한 건만 처리하며 다음 문서가 선행 완료 전에 진행하지 않습니다.
- 기존에 기록된 그래프와 문서는 이 계약에 맞추려고 자동 수정하지 않습니다.
